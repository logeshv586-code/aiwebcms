# Store Designer — No-Code Guide

The Store Designer is built for store owners and content teams. You do not need HTML, CSS, React, or developer knowledge to change the storefront.

## 1. Choose one of the five store designs

Open **Admin → Store Designer**.

Choose the style that best matches the business:

1. **Luxe Editorial** — fashion, beauty and premium brands.
2. **Marketplace Pro** — electronics, general stores and offer-heavy catalogs.
3. **Minimal Studio** — lifestyle, home and modern direct-to-consumer brands.
4. **Fresh Organic** — food, wellness and natural products.
5. **Tech Motion** — gadgets, technology and modern product launches.

Each template has its own spacing, typography, colors, card style, hero treatment and storefront personality.

### Apply design

Use **Apply design** when the store already has homepage content and only the visual style should change.

This changes the global design language while keeping the current homepage sections.

### Use full layout

Use **Use full layout** when you want the selected template's complete recommended homepage arrangement.

This replaces **homepage sections only** after confirmation. Products, variants, categories, collections, brands, customers, orders, payments and other commerce data are not deleted.

## 2. Arrange the homepage

Every homepage section appears as a block in Store Designer.

- Drag a block to move it.
- Use the up/down buttons as an alternative to dragging.
- Use **Visible / Hidden** without deleting a section.
- Use **Edit** to change content and appearance.
- Use the desktop/mobile preview to review the saved storefront.

## 3. Available homepage blocks

The builder supports:

- Hero banner
- Hero slider
- Small offer slider
- Scrolling announcement
- Category grid
- Product grid
- Product slider / carousel
- Collection grid
- Brand grid
- Offer / promo cards
- Image + text story block
- Blog articles
- Promotional banner
- Text section
- Trust / service cards
- FAQ section

Product blocks can be connected to featured products, newest products, a category, collection or brand.

## 4. Change section appearance without code

Each section can control:

- Normal, full or narrow width
- Text alignment
- Image fit
- Top/bottom spacing
- Corner roundness
- Item gap
- Desktop and mobile height
- Desktop and mobile columns
- Section background
- Section text color

## 5. Build other information pages visually

Open **Admin → Pages & FAQ → Pages**.

Custom pages such as About, Shipping, Returns, Privacy, Terms or campaign pages can use visual blocks:

- Heading
- Text
- Image
- Image + text
- Banner / callout
- Button
- List
- Divider

Blocks can be dragged into a new order. Each block also has simple width, alignment, spacing, background, text color and corner controls.

The currently selected store template automatically styles these pages so the whole storefront stays visually consistent.

## 6. Fine-tune the global brand

Open **Admin → Store settings** after choosing a template when you want to change the store's brand details further.

The existing theme controls can adjust light/dark colors, typography preset, product image ratio, page width, section spacing, card/button rounding, header sizing, sticky header behavior, premium motion and smooth scrolling.

## Safe editing notes

- Switching a design does not delete commerce data.
- Installing a full template layout asks for confirmation because it replaces homepage sections.
- Hiding a section is safer than deleting it when the content may be needed later.
- Add meaningful image descriptions for accessibility and SEO.
- Motion respects the visitor's reduced-motion preference.
